# FitLevel

Aplicativo mobile desenvolvido em React Native com Expo, focado em treinos inspirados em personagens.

## 👩‍💻 Integrantes

## 📱 Funcionalidades

- Tela Home com personagens populares

- Tela de busca
- Cálculo de IMC

## 🛠️ Tecnologias

- React Native
- Expo
- JavaScript
